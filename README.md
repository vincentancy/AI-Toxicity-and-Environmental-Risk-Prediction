# 🌍 AI-Based Chemical Toxicity Prediction and Environmental Risk Assessment

## 📌 Project Overview
This project predicts the toxicity of chemical compounds using Machine Learning (XGBoost) and evaluates their environmental risk based on molecular descriptors.

## 🚀 Features
- Chemical Toxicity Prediction
- Environmental Risk Assessment (Rule Based)
- Air Risk Analysis
- Water Risk Analysis
- Soil Risk Analysis
- Interactive Streamlit Web Application

## 🛠 Technologies Used
- Python
- Streamlit
- XGBoost
- RDKit
- Pandas
- NumPy
- Altair

## 📂 Project Files
- `app.py` – Main Streamlit application
- `toxicity_xgboost_model.pkl` – Trained ML model
- `requirements.txt` – Required Python libraries
